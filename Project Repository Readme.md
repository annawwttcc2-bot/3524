# Team Portfolio Website

A responsive, professional, and friendly showcase website introducing our team members from The University of Hong Kong (HKU). Built using HTML5, Tailwind CSS, and lightweight JavaScript.

## 🚀 Live Demo
Once deployed to GitHub Pages, your site will be live at:
`https://<your-github-username>.github.io/<your-repository-name>/`

## 📁 Repository Structure
Place your files in your GitHub repository following this layout:

```text
├── index.html
├── README.md
└── images/
    ├── source1.jpg   (Chris Park photo)
    ├── source2.jpg   (Nina Shan photo)
    ├── source3.jpg   (Herman Yeung photo)
    ├── source4.jpg   (Ari Tang photo)
    └── source5.jpg   (Anna Chan photo)
```

## 🛠️ Quick Deployment Steps

1. Create a public repository on [GitHub](https://github.com).
2. Upload `index.html`, `README.md`, and the `images/` folder with your 5 profile pictures.
3. Go to **Settings** > **Pages** in your repository.
4. Set **Source** to `Deploy from a branch`, choose `main` branch and `/ (root)` folder, then hit **Save**.
5. Your website will be live in 1-2 minutes!
